`dupes.py` finds pairs of vault notes whose fingerprints differ in at most one position. It is correct but far too slow for the 200,000 notes in the vault (O(n^2)). Make `near_duplicates(fps)` fast enough to handle 200,000 fingerprints of length 12 in a few seconds, keeping exactly the same output: a sorted list of index pairs `(i, j)` with `i < j`. Fingerprints in one call all have the same length (1-32 lowercase letters). Identical fingerprints count as pairs too.
