Chess drills use SM-2 spaced repetition. In `drills/sm2.py` implement `review(card, quality) -> Card` returning a NEW Card (do not mutate the input). Card fields: `reps` (int), `interval` (days, int), `ease` (float). Rules: quality is an int 0-5, otherwise ValueError. If quality < 3: reps = 0, interval = 1, ease unchanged. Otherwise: if reps == 0 the interval becomes 1, if reps == 1 it becomes 6, else round(interval * ease) using the OLD ease; then reps += 1. In both branches, when quality >= 3 the ease updates as ease + (0.1 - (5-q)*(0.08 + (5-q)*0.02)), with a floor of 1.3. Also implement `due(card, last_review: date) -> date` = last_review + interval days.
