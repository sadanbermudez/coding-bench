In `invest/returns.py`, implement `twr(valuations, flows) -> float`, the time-weighted return used by the La Pina dashboard. `valuations` is a list of `(date, value)` sorted by date: the portfolio value at the END of each date. `flows` is a list of `(date, amount)` (deposits positive, withdrawals negative) that happen at the START of their date, before that date's valuation; flows on the first valuation date are ignored (the first value is the starting point). For each consecutive pair of valuations, the sub-period return is `(V_end - F) / V_start - 1`, where F is the sum of flows dated after the start date and on or before the end date. Chain the sub-periods: TWR = product(1 + r) - 1. Raise ValueError for fewer than two valuations or a starting value of zero in any sub-period. Flows may be unsorted.
