Write `migrate.py` with `migrate(db_path, migrations_dir) -> list[str]`. Migrations are files named like `001_create_runs.sql`, `002_add_index.sql` (a number, underscore, name). Apply the ones not applied yet, in numeric order (so `010_...` comes after `009_...` and `2_...`), each inside its own transaction, and record each applied version number in a `schema_version(version INTEGER PRIMARY KEY, name TEXT, applied_at TEXT)` table (create it if missing). Return the file names applied in this call. Running it again applies nothing. If a migration fails, roll back that migration only (earlier ones in the same call stay applied), then raise an exception whose message contains the failing file name. Files that do not match the pattern are ignored; two files with the same number raise ValueError before anything is applied. Use sqlite3 from the standard library.
