Implement `parse_headers(pgn: str) -> list[dict]` in `pgn.py`. The input can hold several games. Each game starts with header lines like `[White "Adan, Sergio"]`; return one dict of tag -> value per game, in order. Values may contain escaped quotes (`\"`) and backslashes (`\\`), which must be unescaped. Ignore move text, comments in braces (which may contain brackets and quotes), and blank lines. A game with no headers is not returned.
