Write `rx.py` with `fullmatch(pattern, text) -> bool`, a regular-expression engine (do NOT use the `re` module or any library). It must agree with Python's `re.fullmatch(pattern, text) is not None` on this subset: literal characters; `.` (any character); character classes `[abc]`, ranges `[a-z]`, negated `[^ab]`; grouping `( )`; alternation `|` (alternatives are never empty); the quantifiers `*`, `+`, `?` (applied at most once to an atom, never stacked); backslash escapes `\.`, `\*`, `\+`, `\?`, `\(`, `\)`, `\[`, `\]`, `\|`, `\\` meaning the literal character. The empty pattern matches only the empty string. Malformed patterns (unbalanced parentheses, an unterminated class, a quantifier with nothing to repeat, a trailing backslash) raise ValueError. It must run in polynomial time: a pattern of 30 `a?` followed by 30 `a` against 30 `a`s must return True in well under a second (naive backtracking takes forever).
