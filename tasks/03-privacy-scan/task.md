`router/boundary.py` decides if a prompt contains private data and must stay on the local model. It misses some cases. Make `is_private(text)` return True when the text contains any of: an email address (including ones with `+`, `_` or `.` in the local part, any letter case, and multi-level domains like `uni.ac.uk`), an IBAN (two capital letters, two digits, then 11-30 capital letters/digits, possibly written in blocks of 4 separated by single spaces), or a phone number in international form (`+` then 9-15 digits in total, single spaces or dashes allowed between digit groups). Plain numbers like years, prices or "version 3.14" must not count. Keep `find_private(text)` returning the list of kinds found (`"email"`, `"iban"`, `"phone"`), each at most once, in that order.
