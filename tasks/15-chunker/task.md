`rag/chunk.py` splits a document into overlapping chunks of words for the memory server. `chunk_words(text, size, overlap)` hangs forever for some inputs and drops the end of the text for others. Fix it so that: words are whitespace-separated; each chunk has at most `size` words, joined by single spaces; consecutive chunks share exactly `overlap` words; the last chunk ends at the last word; no chunk is fully contained in the previous one (so stop once a chunk reaches the end); empty text gives `[]`. Raise ValueError if size < 1, overlap < 0 or overlap >= size.
