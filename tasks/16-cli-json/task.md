`stats.py` is a CLI: `python stats.py runs.jsonl` prints a summary of routine runs (one JSON object per line with `name`, `status`, `seconds`). Add a `--json` flag that prints the same summary as one JSON object instead: `{"runs": N, "ok": N, "failed": N, "by_name": {name: {"runs": N, "avg_seconds": X}}}` with avg_seconds rounded to 1 decimal and keys of by_name sorted. Without the flag the output must stay exactly as it is now. Lines that are blank or not valid JSON are skipped in both modes and counted in a warning printed to stderr (`skipped N bad lines`) only when N > 0. A missing file exits with code 1 and a message on stderr.
