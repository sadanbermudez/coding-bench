Implement `route(logits, k)` in `moe.py`: top-k expert routing for one token, pure Python (no numpy). Pick the k experts with the largest logits (ties: lower index first), then softmax over ONLY those k logits (numerically stable: subtract the max). Return a list of `(expert_index, weight)` sorted by weight descending, ties by index ascending.
