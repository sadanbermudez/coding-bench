Agents send tool calls with JSON arguments. Write `validate.py` with `validate(args, schema) -> list[str]` that checks a value against a subset of JSON Schema and returns error messages (empty list = valid). Support: `type` (object, array, string, integer, number, boolean, null; booleans are NOT integers or numbers; integers ARE numbers), `properties`, `required`, `additionalProperties: false`, `enum`, `items` (one schema for all items), `minimum`/`maximum`, `minLength`/`maxLength`, nested to any depth. Each error message must start with the JSON-pointer-like path of the bad value, `$` for the root, then `.name` for properties and `[i]` for array items (e.g. `$.moves[2]: ...`). Report all errors, not just the first; when the type is wrong, report only the type error for that value. A missing required property is reported at the path of the object that lacks it, one error per missing property.
