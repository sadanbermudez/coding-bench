Implement `TTLCache` in `cache.py`: `TTLCache(capacity, ttl, clock=time.monotonic)`. `put(key, value)` stores or overwrites and makes the key most recent; `get(key, default=None)` returns the value if present and not expired (expired means `clock() - stored_at >= ttl`, where stored_at is the time of the last put) and makes it most recent; expired entries are removed when touched. When inserting a new key beyond capacity, first drop all expired entries, then if still full evict the least recently used. `len(cache)` counts only non-expired entries. Capacity < 1 raises ValueError. Standard library only.
